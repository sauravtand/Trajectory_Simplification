# GeoLife Trajectory Visualization

## Project Overview
This project visualizes GPS trajectories from the GeoLife dataset. 
It can plot trajectories of multiple users dynamically, with options to group users per chart.

- Handles the GeoLife dataset structure (`Data/<user_id>/Trajectory/*.plt`)
- Plots trajectories using latitude and longitude
- Dynamic configuration for number of users per chart
