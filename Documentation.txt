# Interactive GeoLife Trajectory Viewer - Documentation

## Imports

import os - for handling folders and file paths
import pandas as pd - to read .plt GPS files into DataFrames
import matplotlib.pyplot as plt - to create plots
from matplotlib.backends.backend_tkagg import FigureCanvasTkAgg, NavigationToolbar2Tk - embed Matplotlib in Tkinter and add zoom/pan toolbar
import matplotlib - for colors
import tkinter as tk - to create GUI windows and buttons
tkinter.ttk - for nicer dropdown widgets

## Configuration

DATA_PATH = "data/geolife/Data" - location of the GeoLife dataset
LINE_WIDTH = 2 - thickness of trajectory lines
FIGSIZE = (8,6) - size of the plot
FONT_TITLE - font style for plot titles
FONT_LABEL - font style for axis labels

## Load Users

all_users = sorted([u for u in os.listdir(DATA_PATH) if u.isdigit()]) - list all user folders like 001,002
current_user_index = 0 - index of the currently displayed user

## Global Variables

lines = [] - store Matplotlib line objects for each trajectory
current_files = [] - list of .plt files for the current user

## Function: read_plt(file_path)

Reads a GeoLife .plt file into a DataFrame, skipping first 6 rows and naming columns: lat, lon, alt, date, etc.

## Function: plot_user(user_id, trajectory_name="All")

Plots all or selected trajectory for a user.

* Clears previous plot
* Resets lines
* Reads all .plt files for the user
* Colors lines distinctly
* Updates trajectory dropdown
* Shows only the selected trajectory if trajectory_name is not "All"
* Sets title, axis labels, grid, facecolor, and legend

## Function: next_user()

Moves to the next user, updates dropdown, and plots user trajectories

## Function: prev_user()

Moves to the previous user, updates dropdown, and plots user trajectories

## Function: select_user(event)

Triggered when a user is selected from the dropdown; updates plot accordingly

## Function: select_trajectory(event)

Triggered when a trajectory is selected from the dropdown; shows only that trajectory

## Tkinter Setup

* root = tk.Tk() - main window
* fig, ax = plt.subplots(figsize=FIGSIZE) - create Matplotlib figure
* canvas = FigureCanvasTkAgg(fig, master=root) - embed plot in Tkinter
* toolbar = NavigationToolbar2Tk(canvas, root) - add toolbar for zoom/pan/save
* frame_controls - frame to hold dropdowns and buttons
* user_dropdown - dropdown to select user
* traj_dropdown - dropdown to select trajectory
* prev_button / next_button - buttons to navigate users

## Initial Plot

plot_user(all_users[current_user_index]) - plot the first user when program starts

## Main Loop

root.mainloop() - start Tkinter GUI loop
